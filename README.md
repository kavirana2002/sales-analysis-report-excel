# 📊 Sales Analysis Report | Excel

A data analytics project built using **Microsoft Excel** to analyze and visualize sales data. This project covers 6 key business questions answered through Pivot Tables, Charts, Formulas, and an interactive Dashboard.

---

## 📌 Project Overview

This project provides a comprehensive view of sales performance metrics, helping users understand customer demographics, order trends, channel performance, and top-selling products through interactive Excel visuals.

---

## 🎯 Objective

To analyze sales data using Microsoft Excel and answer key business questions through Pivot Tables, Charts, Formulas, and an interactive Dashboard.

---

## 🛠️ Tools & Technologies

| Tool | Purpose |
|------|---------|
| **Microsoft Excel** | Data analysis & dashboard creation |
| **Pivot Tables** | Data summarization & grouping |
| **Charts & Graphs** | Visual representation of data |
| **Formulas & Functions** | Custom calculations & metrics |
| **Dashboard Sheet** | Interactive summary view |

---

## ❓ 6 Analysis Questions Solved

| # | Question | 
|---|----------|
| Q1 | Men vs Women — who has higher sales? |
| Q2 | What is the order status breakdown? | 
| Q3 | Sales analysis based on Age & Gender | 
| Q4 | Which channels are used the most? |
| Q5 | Top 5 best selling products | 
| Q6 | Orders vs Sales trend | 

---

## 📊 Dashboard Features

- 🔄 **Pivot Tables** — Summarized data by gender, age group, channel, and product category
- 📈 **Charts & Graphs** — Bar charts, pie charts, line graphs and combo charts for each analysis question
- 🧮 **Formulas & Functions** — SUMIF, COUNTIF, VLOOKUP and other Excel functions for custom calculations
- 📋 **Interactive Dashboard** — All 6 insights combined in one clean dashboard view with slicers

## 🚀 How to Use

1. **Clone or download** this repository
2. Open the `.xlsx` file in **Microsoft Excel**
3. Navigate through the sheets:
   - **Data Sheet** — Raw sales data
   - **Analysis Sheets** — 6 question-wise analysis
   - **Dashboard Sheet** — Complete interactive view
4. Use **slicers and filters** to explore the data interactively!
